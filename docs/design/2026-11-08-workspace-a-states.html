The batch finished. The dock holds the terminal state; the destination pane refreshed and selected the new file.

The data channel timed out; the control session is still up. The dock names the failure and promises no partial output; the source stays selected for a manual retry.

The control channel dropped. The pane offers reconnect, the dock keeps the failed transfer visible, and the local pane is still usable.

Local folder empty, remote listing in progress. Each pane names its state instead of showing a blank list.

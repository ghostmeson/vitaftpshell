vitaFTPShell — SERVER directions

The SERVER screen starts and stops the anonymous server, shows where to connect, and keeps the risk visible. Three compositions; the state, address, port, warning, and one client are the same. Direction-only.

960 × 544 header 64 px dock 64 px state px 5 type 5×7 face, 1.5 / 2 / 3 / 5 px
AConsole

Left status panel with the big state, address, port, clients, and the stop control; right warning and client panels. The warning has its own surface, so it cannot be mistaken for a readout.

BBands

A wide status band, a full-width warning band, and a client band. The risk is unmissable and the state is a horizontal hero; the screen reads top to bottom.

CInstrument

One panel holds the state, address, readouts, warning, client, and stop control. Densest, but the warning shares the surface with the status.

State shown: server ON, one client browsing /UX0:/DATA/, stop control focused, client role not connected.

Not shown: OFF at launch, starting, bind failure, no network, a second client, stopping during a write, and the transfer dock when the server client moves a file.

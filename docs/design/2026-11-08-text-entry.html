vitaFTPShell — TEXT ENTRY

The system IME is a Vita surface: the app supplies a title, an initial value, a password flag, and a maximum length, and the IME returns UTF-8 or cancellation. The app never draws the keyboard. The first frame’s lower area is a contract placeholder, not the IME’s look.

960 × 544 IME area 960 × 300 returns UTF-8 or cancel type 5×7 face, 1.5 / 2 / 3 px
1Open

The IME on the site name. The app passes SITE NAME, HOME NAS, MASKED NO, MAX 64; the Vita draws the keys and its own OK / CANCEL. The editor stays behind.

2Cancelled

The IME is dismissed. The field keeps its previous value, no error is shown, and the editor returns with the same focus. The user can try again.

3Unavailable

The IME cannot open. The app reports TEXT ENTRY UNAVAILABLE, keeps the previous value, and says the field is unchanged. Circle backs out; nothing is lost.

Contract: the IME opens with a title, an initial value, a password flag, and a maximum length; it returns UTF-8 or cancellation. Cancellation keeps the previous value and the caller’s state. A password uses the IME’s masked mode and never reaches the log. The port is validated by the app at 1–65535; the names and hosts use the normal field rules.

Titles and caps: SITE NAME 64 · HOST 255 · PORT 5 · USERNAME 64 · PASSWORD 128 (masked) · NEW FOLDER NAME 255 · RENAME 255.

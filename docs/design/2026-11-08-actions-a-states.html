vitaFTPShell — ACTIONS, direction A states

Direction A is chosen: the action ledger with the target panel, and local copy/move use the marks as the source and the current folder as the destination. This sheet develops the four states.

960 × 544 actions 552 × 352 target 360 × 352 dock 64 px type 5×7 face, 1.5 / 2 / 3 / 5 px
1Local single, no marks

No marks. Copy and move are dim because the destination model needs a mark; upload, new folder, rename, and delete use the cursor. The target shows the current item and the upload destination.

2Local multi

Three marks. Copy and move go to the current folder; rename needs one item; delete is flagged. The destination is stated twice: the path and DESTINATION THIS FOLDER.

3Remote single

One remote file. Download to the local pane; rename, delete, new folder. The destination is the local pane.

4Protected root

A volume root. Copy, move, rename, and delete are dim; new folder is the only action. The reason is named on the target.

Settled in this pass: the 552 action ledger and 360 target; the target states the item or marks, the path, the destination, and the selected action’s consequence; local copy/move need a mark and go to the current folder; a local single keeps upload, new folder, rename, and delete; the remote single downloads to the local pane; a volume root dims every destructive and copy action and leaves new folder.

Still open: the remote multi state; a disconnected remote pane; the copy-into-itself refusal copy; and the delete confirmation, which belongs to CONFIRM. Marks stay after a copy or move (D18).
